# Pooja Ladies Tailor Website

A static website built with HTML, CSS, and JavaScript. No build tools or package installation are required.

The hero illustration and logo image are stored locally in `assets/images/`.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html`, `README.md`, and the `assets` folder, preserving its folder structure.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Once deployment finishes, open the Pages URL shown in the repository settings.

The enquiry form opens WhatsApp with a pre-filled message. The visitor sends it from WhatsApp.
